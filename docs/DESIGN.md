# 医学稿件处理系统设计规范

## 设计方向

采用“黑金学术编辑工作室 + 任务流中台”的方向：保留现有黑金品牌感，但布局必须简洁、密度更高、路径更清晰。界面优先服务高频稿件处理，而不是展示大量装饰性卡片。

## 核心原则

- **主任务优先**：每个页面只突出一个主任务，例如选择稿件、执行模块、查看结果、人工确认。
- **强列表/强表格**：列表和表格要比大卡片优先，尤其是稿件队列、规则、知识库、执行记录。
- **卡片克制**：卡片只用于分组和状态，不用于堆叠说明文案；内部间距保持紧凑。
- **进度显性化**：初筛、编辑、校对三大模块必须提供清晰实时状态和进度反馈。
- **子页面独立承载**：校对、编辑、结果详情等深度操作页面不得塞在小面板里，应给足正文、问题列表和操作区空间。
- **不破坏业务语义**：UI 改造不改变 API、权限、稿件状态流转，除非明确列为产品需求。

## 视觉系统

- **主题**：黑金为主，纸张暖白为内容底色。
- **主色**：`#d8be84` 用于关键状态、进度、焦点和主按钮。
- **深色面板**：`#1b1712` / `#181510` 用于壳层、主按钮、强调态。
- **内容面板**：`#fffaf2` / `#f6f1e8` 用于正文、表格、列表和表单。
- **危险状态**：`#7f3428`，只用于阻断性错误或需要人工介入的状态。

## 组件策略

- 新 UI 使用 `Tailwind CSS` 和 `src/components/ui` 下的 shadcn 风格组件。
- 旧 CSS 暂不删除；新页面和重构页面优先使用新组件层。
- 基础组件优先覆盖：`Button`、`Card`、`Badge`、`Progress`、`Table`。
- 后续按需要增加：`Tabs`、`Dialog`、`Sheet`、`ScrollArea`、`Tooltip`。

## 页面布局

- **工作台首页**：左侧稿件队列，右侧当前稿件操作；三模块进度始终可见。
- **稿件详情/校对页**：独立大页面，建议三栏：正文/预览、问题列表、操作确认。
- **规则/模板/知识库**：以表格和筛选器为主，卡片只放汇总和关键入口。
- **系统设置**：设置导航 + 表单面板，避免所有表单堆在一个长页面。
